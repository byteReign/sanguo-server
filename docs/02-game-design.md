# 三国砍王 - 游戏策划文档（V0）

## 项目定位

三国题材文字挂机成长游戏。

玩家扮演乱世中的一名小兵，从黄巾之乱开始征战，通过挂机、点击、收集图鉴和称号不断成长。

---

## 核心玩法

玩家拥有：
- **战力**：角色总战斗力
- **DPS**：每秒自动造成的伤害
- **称号**：根据击败敌人数量解锁
- **图鉴**：首次击败敌人后解锁

**战斗方式**：
- 系统自动造成伤害（DPS）
- 玩家点击可获得额外伤害
- 敌人死亡后自动进入下一关

## 伤害机制

**全部按真伤计算**，不考虑防御、减伤、抗性等复杂机制。

- 升级获得的属性 → 直接加真伤
- 装备提供的属性 → 直接加真伤
- 称号加成 → 直接加真伤
- 战法/被动 → 直接加真伤或百分比加成

**公式**：
- 点击伤害 = 基础点击伤害 + 装备真伤 + 称号真伤 + 其他加成
- 每秒伤害（DPS）= 基础DPS + 装备DPS + 称号DPS + 其他加成

**设计目标**：
- 前期简单直观，玩家看得懂
- 后续要加防御/减伤机制时，只需在伤害计算层加一层过滤
- 数值膨胀可控，真伤就是最终伤害

## 成长系统

击败敌人获得：
- **等级**：提升等级获得属性点
- **真伤**：直接增加伤害数值

**属性点分配**（V0 简化版）：
- 升级自动分配，不手动加点
- 每级固定增加：点击真伤 +1，DPS +1

**装备系统**（V1 扩展）：
- 击败 Boss 掉落装备
- 装备属性：点击真伤、DPS、离线收益加成
- 同类型装备只能装备一件

**称号加成**：
- 称号提供固定真伤加成
- 例如：乡勇 → 点击真伤 +1，DPS +1

## 图鉴系统

首次击败敌人自动解锁。

**示例**：
```
【黄巾兵】
东汉末年黄巾起义军士卒。
解锁时间：2026-06-02
```

**图鉴奖励**：
- 每解锁一个图鉴，永久 +1 DPS

## 数值平衡原则

1. **前期快**：前10关让玩家快速体验成长感
2. **中期稳**：10-50关保持稳定的成长节奏
3. **后期慢**：50关后需要策略性成长
4. **点击有意义**：在线时点击收益明显高于纯挂机
